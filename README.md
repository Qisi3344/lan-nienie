# 小海捏捏 🫧🐾

一盒薄荷蓝透明史莱姆「小海」，用猫爪去揉、去按、去拉丝的手机小玩具。纯原生 JS + WebGL，无依赖。

## 玩法
- 一根手指 = 一只猫爪，两根 = 两只；按下去是肉垫形状的坑，松手慢慢回流
- 长按约 0.33 秒再拖 = 拉丝，拉太长会断、回缩并冒泡泡
- 两只爪合拢 = 对折
- 底栏：↺ 抚平 / ＋ 泡沫珠 / ＋ 亮片 / 🫧 吹泡泡

## 运行
需要浏览器支持 WebGL，且要通过本地服务器打开（不能直接双击 html）：

```bash
npx serve .
# 打开 http://localhost:3000 ，手机同一 Wi-Fi 下访问电脑 IP 也行
```

## 结构
```
index.html          页面外壳
css/style.css       少量样式
src/slime.js        全部逻辑：200² 高度场、斜俯视射线求交着色器、猫爪/装饰/拉丝/泡泡、WebAudio 音效
test/render-overlay.js  离线测试：node 里模拟拉丝并画出叠加层（需 @napi-rs/canvas）
```
