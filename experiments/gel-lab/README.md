# 小海 · 真正黏弹性材料 2D 实验室

> **独立物理实验，不是正式 3D 成品。** 这次不是把一条透明丝贴在史莱姆上，而是抓住构成胶体的粒子本身。物体几何始终从这些持久粒子重建。

[打开在线实验台](https://raw.githack.com/Qisi3344/lan-nienie/experiment/viscoelastic-material-2d/experiments/gel-lab/index.html)

## 交互
- 直接按住胶体，往上、往左、往右拖拽；放开会受重力和黏弹连接作用下落。
- 支持双指拖拽；两种力度旋钮：黏稠度、回弹度；可显示材料点，验证没有额外假丝。
- 若按到了胶体外部不会凭空生成史莱姆。

## 物理 (算法方向)
- 400 个初始质量相同且永久存在的材料粒子，**不使用额外“拉丝物体”**。
- 空间哈希近邻搜索、黏性速度冲量、双密度松弛 (DDR)、动态弹簧 / 塑性松弛 / 超伸断裂和接触后再连接。
- 碰撞约束与两个独立指针抓取；固定时步，每帧两个求解子步。
- 渲染依据**同一批粒子**生成连续密度场和半透明薄荷色着色；所有外观由材料场决定。

## 实际限制（避免误解）
- 这是**二维竖向剖面**的物理概念验证，不是完整 3D 模拟、也不是可准确预测商品史莱姆应力-应变曲线的科学模型。
- 粒子间黏弹连接提供有依据的近似；此版尚不能保证真实比例的细长薄膜、复杂三维扭结与手指抓取的立体咬合。
- 当前移动端粒子预算针对验证用途设置；帧率须在手机实测。未与正式版的猫爪/海豚/背景/音效整合。
- 如果需要“真正的 3D”，下一个阶段要使用 3D 粒子 + 邻域约束，再由 WebGL2 密度场/表面重建或 WebGPU 表面重建输出；不能只将二维渲染旋转假装 3D。

## v0.2 可视与交互改善（2026-10-15）

- 史莱姆初始化从 245 粒扩大到 **400 粒**，整团材料占据盆内大部分宽度；避免只剩一坨小胶球。
- 画布从 640×520 调为 640×430，减少无关空白区域；玻璃盆改为更宽的侧面剖视。
- 抓取范围由 9 个点调整为最多 25 个材料点，形成更宽的物质牵引区；依然不额外制造拉丝。
- 重设凝胶边缘密度重建、半透明渐层、由材料点绑定的星点；材质和光线尚属艺术近似。
- 自动测试增加 **胶体宽度超过 400 像素** 的回归保护；数值抓取回落和完整粒子 ID 测试保留。
- 已通过 **固定 Git commit 的浏览器渲染检查**：新版显示 400 粒和 26%/34% 初始参数，非旧 CDN 缓存；浏览器中无可见报错。
- 尚未完成真实手机长按与多触点验收；网页显示的 FPS 不是 iPhone 性能保证。

## 运行与验收
```sh
# 在项目根目录
npm run test:gel
npx serve .
# 进入 /experiments/gel-lab/
```

观察同一批粒子：拉起前、拉起时、松手后粒子数量及 ID 恒定。手机触摸的完整回归应在实际 Safari/Chrome 上测。
